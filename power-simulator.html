Data Center Power Consumption Simulator

MIT Laboratory for Information and Decision Systems · June 2026 – Sept. 2026

Overview

Engineered a Python framework to translate time-varying compute workloads into realistic 24-hour data center electrical load profiles. The system bridges software activity and physical facility infrastructure, providing a configurable tool for analyzing how different computational workloads and deployment architectures impact grid demand.

Key Accomplishments & Engineering Work

  • Multi-Tier Power Pipeline: Developed an end-to-end modeling pipeline mapping raw activity traces through a physics-based power chain — workload trace → server utilization → server IT power → cluster IT power → total facility power (via PUE).
  • Hardware & Facility Modeling: Built parametric models combining baseline server power states (idle and peak) with adjustable facility Power Usage Effectiveness (PUE) to quantify non-IT overhead such as cooling, UPS losses, and distribution.
  • Multi-Workload & Architecture Support: Characterized 5 distinct workload classes — General Compute, Storage, Batch Analytics, AI Inference, and LLM Training — across 5 facility deployment environments, from enterprise to hyperscale AI and edge.
  • Interactive Simulation Dashboard: Built a Streamlit web application allowing real-time parameter configuration, 24-hour time-series visualization, and instant calculation of peak demand, daily energy, and load factor.

Tech Stack & Tools

  • Language & Core Libraries: Python, NumPy, Pandas, SciPy
  • Visualization & Interface: Streamlit, Plotly / Matplotlib
  • Domain Concepts: Data center infrastructure, Power Usage Effectiveness (PUE), hardware power modeling, workload trace characterization
