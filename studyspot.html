StudySpot

MIT Web.lab · Jan. 2026 · Hackathon Semifinalist (~30 teams)

Overview

Co-designed and developed an interactive study spot discovery web platform that helps students and remote workers find, rate, and review local workspaces. The application combines interactive map-based search with real-time spatial filtering, detailed review profiles, and secure user account management.

Technical Architecture & Key Accomplishments

  • Interactive Front-End & Mapping: Built a React interface integrating map features to display nearby study spots with dynamic markers, amenity tags, and real-time location filtering.
  • RESTful API & Database Architecture: Designed a Node.js/Express REST API paired with MongoDB (Mongoose) to efficiently query, update, and manage geospatial location data, user reviews, and rating metrics.
  • Authentication & User Management: Implemented secure user authentication using JSON Web Tokens and bcrypt to manage user profiles, saved spots, and review permissions.
  • Deployment & Recognition: Configured end-to-end continuous deployment on Render for production hosting; earned semifinalist recognition in a showcase competition featuring roughly 30 engineering teams.

Technical Stack & Tools

  • Front-End: React.js, JavaScript (ES6+), HTML5/CSS3, interactive mapping APIs
  • Back-End: Node.js, Express.js, REST APIs, JWT authentication
  • Database: MongoDB, Mongoose ODM
  • Deployment & DevOps: Render, Git/GitHub version control
