Biomechanics Video Segmentation Automation

MIT Newman Lab for Biomechanics · Jan. 2026 – June 2026
→ View Repository on GitHub

Overview

Developed an automated computer vision and video processing framework to eliminate manual annotation across large-scale biomechanical manipulation datasets. The system tracks subject hand and wrist kinematics in real time, validates movement through spatial zones, and automatically extracts synchronized, frame-accurate clip segments across dual-camera (L/R) video feeds.

Raw dual video feeds → MediaPipe Pose Landmarker → spatial & temporal smoothing (deque) → state-machine zone detection → automated frame-segment cutter → synchronized output clips

Key Features & Technical Implementation

  • Spatial-Temporal Kinematic Tracking: Integrated Google MediaPipe's Pose Landmarker to track wrist and hand landmarks, using a deque-based moving average buffer to smooth positional noise and filter sudden velocity artifacts.
  • State Machine & Hold-Time Validation: Built a state-driven detection algorithm requiring spatial boundary containment and a minimum hold time to distinguish intentional interactions from momentary hand passes.
  • Interactive Calibrator GUI: Implemented real-time keyboard controls overlaid on the OpenCV video preview for dynamic spatial zone positioning and threshold tuning during dataset setup.

Repository Structure & Pipeline Scripts

  • get_frames.py Extracts and processes raw frame sequences from video feeds, computing exact frame indices and timestamps required for precise down-pipeline segmentation and alignment. It uses Google MediaPipe to track wrist landmarks across frames and applies trajectory smoothing to filter out noise and sudden position jumps.
  • video_cut.py The central execution script that reads validated timestamp logs, seeks to exact target frame indices using OpenCV, and writes synchronized, trimmed MP4 clips for dual-camera (L/R) video streams.
  • pose_visualization.py Batch-processes MP4 video feeds using MediaPipe Pose Landmarker in video mode to extract 2D pixel coordinates for upper-limb joints (shoulder, elbow, wrist). Validates joint visibility thresholds (> 0.5), overlays skeleton connections, and exports serialized coordinate trajectories to NumPy files for kinematic modeling.
